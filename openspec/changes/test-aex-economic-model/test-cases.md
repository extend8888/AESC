## 测试用例格式说明

每个测试用例包含以下字段：

| 字段 | 说明 |
|------|------|
| **Case ID** | 唯一标识符，格式：`TC-{章节}-{序号}` |
| **需求来源** | 对应需求文档的章节和条款 |
| **描述** | 测试目的和场景 |
| **前置条件** | 执行测试前需要满足的条件 |
| **测试步骤** | 详细的操作步骤 |
| **期望结果** | 预期的系统行为 |
| **实际结果** | 执行后填写，包含通过/失败状态 |
| **备注** | 额外说明或问题记录 |
