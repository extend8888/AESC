# AEX 经济模型压力测试脚本

本目录包含用于验证 AEX 经济模型特定场景的测试脚本。

## 代币说明

本链使用双代币模型：

| 代币 | Denom | 用途 |
|------|-------|------|
| **AEX** | `uaex` | Gas 代币，用于交易手续费 |
| **STAEX** | `ustaex` | 质押代币，用于质押/治理/投票 |

- **1 AEX = 1,000,000 uaex**
- **1 STAEX = 1,000,000 ustaex**

## 目的

验证以下需要特殊条件的测试用例：

| Case ID | 测试项 | 所需条件 |
|---------|--------|----------|
| TC-2-03 | 通胀触发条件 | Gas 使用率 > 50% |
| TC-3-02 | 动态销毁-低使用率 | 多个 epoch + 低负载 |
| TC-3-03 | 动态销毁-高使用率 | 多个 epoch + 高负载 |
| TC-5-02 | 验证者通胀补贴 | 触发通胀条件 |

## 配置特点

与标准 `scripts/` 目录的区别：

1. **更小的初始供给** - 便于快速观察供给变化
2. **更短的 epoch 周期** - 便于快速验证周期性逻辑
3. **更低的通胀触发阈值** - 便于在低负载下触发通胀

## 脚本说明

| 脚本 | 功能 |
|------|------|
| `deploy.sh` | 一键部署压力测试环境 |
| `step1_configure_init.sh` | 初始化节点（少量代币配置） |
| `step2_genesis.sh` | 生成 genesis（低阈值参数） |
| `step3_config_override.sh` | 配置覆盖 |
| `step4_start_sei.sh` | 启动节点 |
| `run_stress_test.sh` | 执行压力测试（批量交易） |

## 使用方法

```bash
# 1. 清理旧环境
./poc-deploy/localnode/scripts/clean.sh

# 2. 部署压力测试环境
./poc-deploy/localnode/stress-test-scripts/deploy.sh

# 3. 执行压力测试
./poc-deploy/localnode/stress-test-scripts/run_stress_test.sh
```

## 注意事项

- 这些脚本仅用于测试，不要用于生产环境
- 测试完成后建议清理环境，恢复正常配置

## 测试结果 (2026-01-19)

**关键发现**：

1. **销毁功能正常** ✅
   - 销毁比例: 50% (target_burn_rate)
   - 每次销毁: 9164 uaex

2. **通胀未触发** (符合预期)
   - 实际 Gas 使用率: 0.01% (峰值)
   - 通胀触发阈值: 10%
   - 结论: 需要更高负载才能触发通胀

3. **验证者奖励正常分配** ✅
   - 累计奖励: 166,666,704,826 uaex

## 如何触发通胀

要触发通胀，需要 Gas 使用率超过阈值 (10%)。可能的方法：

1. 部署复杂智能合约并批量调用
2. 使用 EVM 批量交易工具
3. 进一步降低 `min_gas_usage_for_inflation` 参数
